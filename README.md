# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This portfolio showcases my skills, projects, education, and contact information. It is designed to present my work professionally and provide recruiters and developers with an overview of my technical abilities.

## 🚀 Live Demo

👉 https://tulasibobbara.github.io/tulasi-portfolio/

---

## 📌 Features

- Responsive design for desktop and mobile
- Modern dark-themed user interface
- Typing text animation
- Sticky navigation bar
- Animated skill progress bars
- Project showcase section
- Resume download/view button
- Contact information with GitHub and LinkedIn
- Smooth scrolling and hover animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## 💻 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/tulasibobbara/portfolio.git
```

2. Open the project folder.

3. Open `index.html` using Live Server in VS Code.

or simply double-click `index.html`.
